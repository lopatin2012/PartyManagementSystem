Параметры в файле .env для запуска системы.

# Режим работы сервиса.
DEBUG -> Указывать 0 или 1. 0 -> запустится прод. 1 -> запустится отладочный режим.
# Секретные настройки приложения.
SECRET_KEY -> Секретный ключ.

# Настройки подключения к Базе Данных.
DB_NAME -> Имя БД.
DB_PASSWORD -> Пароль БД.

# Настройки времени.
TIME_ZONE -> Часовой пояс.

# Контроль версий.
"pip install -e ." -> сборка версии.
Исправление бага, fix: 1.0.0 -> 1.0.1.
Новая фича, feat: 1.0.0 -> 1.1.0.
Поднятие версии с помощью tag:
    git tag 2.0.0: 1.0.0 -> 2.0.0.
    git tag -a v1.2.0 -m "Release version 1.2.0"
