# Документация проекта «Молвест.СистемаУправленияПартиями»

Папка `docs/` — локальная (внесена в `.gitignore`), в git не попадает.

## Назначение комплекта

Документы покрывают четыре задачи:

1. **Понять, как устроен проект** — архитектура, модели, интеграции.
2. **Составить техническое задание (ТЗ)** — каркас и требования.
3. **Сделать презентацию** — структура и тезисы слайдов.
4. **Обучить сотрудников** — пошаговые сценарии и FAQ.

## Состав

| Файл | Для чего |

| `06-operations.md` | Запуск, конфигурация, миграции, CI/CD, деплой, эксплуатация |

| `08-training.md` | Обучение сотрудников: сценарии работы и FAQ |

## Связанные файлы в этой папке

- `Техническое задание проекта ... .docx` — актуальное ТЗ (Word).
- `PartyManagementSystem_презентация.pptx` — презентация для показа.

## Как поддерживать

- При изменении кода, моделей, API или ролей — обновляйте соответствующий файл и `CHANGELOG.md`.
- Источник истины по командам и конвенциям — корневой `AGENTS.md` и `README.md` проекта.
- Расписание задач — список `SCHEDULE` в `app_scheduler/management/commands/run_scheduler.py`.
