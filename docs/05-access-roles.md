# 05. Роли и доступ

## Модель

Доступ разграничивается **встроенными группами Django** (не `is_superuser`).

| Роль (группа) | Возможности |
| --- | --- |
| **«Админ»** | Полный доступ: список УИП, генерация и резервирование, синхронизация заданий, Национальный каталог, фоновые задачи, настройки СУЗ |
| **«Просмотр»** | Только страница УИП. Генерация УИП — если дополнительно выдано право на запись в модель `uip` (`app_uip.add_uip` / `change_uip`) |

- **Суперпользователь** и **staff** всегда считаются администраторами.
- Главная (`/`) и поиск (`/search/`) — публичные (без входа).
- Страница УИП (`/uip/`) — вход + роль «Админ»/«Просмотр» (или право `app_uip.view_uip`).
- Административные разделы — только «Админ».

## Автосоздание групп

Группы создаются автоматически по сигналу `post_migrate` (`app_helper/signals.py`):

- «Админ» — все права;
- «Просмотр» — право `app_uip.view_uip`.

Достаточно выполнить `python manage.py migrate` (уже делается в CI и `deploy.sh`/`deploy.ps1`).

## Хелперы (`app_helper/access.py`)

| Функция | Смысл |
| --- | --- |
| `is_admin(user)` | суперпользователь **или** staff **или** группа «Админ» |
| `can_view_uip(user)` | админ **или** группа «Просмотр» **или** право `view_uip` |
| `can_generate_uip(user)` | админ **или** право `add_uip`/`change_uip` |

Также: миксины `AdminRequiredMixin`, `UipPageAccessMixin`; декораторы `admin_required`,
`admin_required_json`, `generate_uip_required_json`; DRF-права `IsAppAdmin`, `CanGenerateUip`.

В шаблонах доступны флаги контекста: `is_admin`, `is_viewer`, `can_view_uip`, `can_generate_uip`
(`config/context_processors.user_context`).

## Как назначить доступ

1. Убедиться, что миграции применены (созданы группы).
2. `/admin/` → «Пользователи» → нужный пользователь → «Группы»:
   - «Админ» — полный доступ;
   - «Просмотр» — только страница УИП.
3. Чтобы «Просмотр» мог генерировать УИП — выдать право `app_uip | add_uip` (или `change_uip`)
   (в карточке пользователя «Права пользователя» либо через отдельную группу).

## Что видит каждая роль

| Элемент | Админ | Просмотр |
| --- | --- | --- |
| Страница УИП `/uip/` | да | да |
| Кнопка «Синхронизировать с ЧЗ» | да | нет |
| Кнопка «Сгенерировать УИП» | да | только при праве записи |
| Резервирование черновой УИП | да | нет |
| Разделы «Синхронизация», «Нац. каталог» | да | нет |
| Виджет «Фоновые задачи», настройки СУЗ | да | нет |

## Ошибки доступа

- Анонимный пользователь на защищённой странице → редирект на `/auth/login/`.
- Авторизованный без роли → страница `403` («Доступ запрещён») с пояснением.
- Несуществующая страница → `404`.
