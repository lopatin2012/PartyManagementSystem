# CHANGELOG (документация и проект)

Формат: дата — раздел — изменение. Ведётся по документации и ключевым изменениям проекта.

## 2026-10-02

### Наблюдаемость и алерты (`app_event`)
- Письма-алерты стали информативными: **текст + стилизованный HTML** с сервисом,
  статусом, временем, числом сбоев, датой начала (`Сбой с`), сообщением и разбивкой
  по заводам. `_diagnose` собирает подробные детали (заводы N/M, СУБД/хост,
  СУЗ/ИНН/срок токена, нагрузка).
- Сбой подтверждается только после `HEALTH_CONFIRM_ATTEMPTS` неудачных проверок
  подряд (по умолчанию **3 → ~15 мин**); одиночные «мигания» сети письма не шлют,
  алерт приходит один раз, восстановление — только после подтверждённого сбоя.

### СУЗ / TrueAPI
- `refresh_suz_dynamic_token()` делает до **3 попыток**, затем прекращает.
- Добавлено **проактивное обновление** динамического токена за час до истечения
  (`ensure_suz_token_valid()`); вызывается из проверки состояния каждые 5 минут —
  закрывает разрыв между плановой задачей (6 ч) и жизнью токена (8 ч).
- Получение токена сессии возвращает безопасный контракт (`uuidToken` первым,
  без исключений) — резерв/генерация больше не падают с 500 при сбое TrueAPI.
- Исправлена генерация через ЧЗ: `productionDate` отправляется полным ISO 8601
  (`2026-10-02T00:00:00.000Z`); `_generate_cz_uip` получает объект `ProductSKU`.

### Синхронизация с Молвест.Маркировка
- Синхронизация кодов (этап 2) ограничена заданиями **«В работе»/«Закрыто»**,
  созданными за последние **3 дня** (поле `ProductionParty.external_created_at`,
  мапится из `datetime_create`).

### Страница `/uip/`
- Компактный блок «Молвест.Маркировка» на главной — сеткой чипов.
- Кнопка-фильтр **«В рассинхроне»** (`?desync=1`) и действие **«Проверить в ЧЗ»**
  (`POST /cz/api/check-uip-cz/`): попытка зарезервировать номер напрямую в ЧЗ.
  Успех → `reserved_local` + снятие `is_desync`; отказ → «зарегистрирован», статус
  не меняется.
- НатураПРО: предпросмотр и ввод приведены к серверному формату (7-значный номер
  партии, без авто-добавления год/неделя/день).

## 2026-09-21

### Документация (docs/)
- Создан комплект документации: обзор, архитектура, интеграции, API, роли/доступ,
  эксплуатация, тестирование, обучение, каркас ТЗ, структура презентации.
- `docs/` внесена в `.gitignore` (локальная папка, в git не попадает).

### Доступ и роли
- Введена ролевая модель на встроенных группах Django: «Админ» и «Просмотр»
  (`app_helper/access.py`, автосоздание групп через `post_migrate` в `app_helper/signals.py`).
- Страница `/uip/` требует входа и роли; генерация УИП — по праву на запись в модель `uip`
  (`app_uip.add_uip`/`change_uip`).
- Административные разделы переведены с `is_superuser` на `is_admin`.
- Добавлены страницы ошибок `403`/`404`.

### Поиск
- Результаты поиска (`/search/`) переведены с таблицы на **карточки**.
- В карточках отображается внешний номер задания, завод, цех, линия, артикул и др.

### Надёжность синхронизации
- Персональная метка синхронизации по каждому заводу (`Factory.external_sync_changed_since`);
  при сбое выгрузки метка не сдвигается.
- Задача синхронизации помечается FAILED при ошибках; быстрый повтор через 5 минут.
- Ручной полный запуск: `POST /cz/sync/all/` (задания + коды).

### Презентация

- Добавлен слайд «Эффект в цифрах» (оценочные показатели).
