# 01. Обзор проекта

## Что это

**«Молвест.СистемаУправленияПартиями»** (PartyManagementSystem) — монолитное веб-приложение для
управления производственными партиями и кодами маркировки в интеграции с государственной
системой «Честный Знак» (СУЗ / TrueAPI).

Система ведёт полный жизненный цикл **УИП** (уникального идентификатора партии) и **кодов
маркировки DataMatrix (CIS)** всех уровней агрегации, связывая производство, локальные серверы
маркировки и учётные системы предприятия.

## Зачем (проблема)

- Маркировка «Честный Знак» обязательна и строго регламентирована: ошибки ведут к блокировке
  кодов, штрафам и остановке отгрузки.
- Данные о партиях и кодах разбросаны между системами: производство (MES), склад (WMS),
  1С, локальные серверы «Молвест.Маркировка».
- Много ручных операций: резервирование, контроль сроков, снятие с резерва, сверка статусов,
  подстановка номера/GTIN в отчёты.
- Нет единой истории и прослеживаемости: сложно быстро ответить, где, когда и в какой партии
  выпущен код.

## Решение

Единый сервис — «мастер» по УИП и кодам маркировки:

- генерация, резервирование и учёт УИП;
- приём и хранение кодов CIS с иерархией «единица → коробка → паллета»;
- автоматическая двусторонняя синхронизация с «Честным Знаком» и локальными серверами
  «Молвест.Маркировка»;
- единый REST API для смежных систем (1С, MES, WMS);
- полный аудит изменений и прослеживаемость;
- разграничение доступа по ролям.

## Бизнес-ценность

| Направление | Эффект |
| --- | --- |
| Единый источник правды | Нет дублей и рассинхрона по УИП и кодам между системами |
| Автоматизация | Резервирование, контроль сроков, снятие с резерва, архивация — без ручного труда |
| Прослеживаемость | Полная история: код → партия → линия → завод → отгрузка |
| Надёжность | Система переживает сбои и догоняет пропущенные данные |
| Прозрачность | Статусы и отчётность доступны смежным системам и управлению |
| Масштабируемость | Мультизаводность, контейнеризация, автодеплой |

## Области внедрения

- **MES** — считывание и фиксация УИП на линиях, обмен с «Молвест.Маркировка».
- **WMS** — контроль движения партий на складе (модуль-заготовка).
- **1С (ERP / УХ / УПП)** — учёт, отчётность, закрытие периодов через REST API.
- **«Честный Знак»** — резервирование, отчёты о нанесении, статусы кодов.
- **Национальный каталог (ГИС МТ)** — синхронизация номенклатуры.

## Жизненный цикл УИП

Статусы (`app_uip.models.PartyStatusChoices`):

```
draft → reserved_cz / reserved_local → registered → closed → archived
                                          │
                                          └── deleted (сгорел через 30 дней без отчёта)
```

- `draft` — черновик, ЧЗ о нём не знает.
- `reserved_cz` — сгенерирован средствами ЧЗ (живёт 30 дней).
- `reserved_local` — свой номер, зарезервирован в ЧЗ (живёт 30 дней).
- `registered` — отправлен отчёт о нанесении.
- `closed` — партия закрыта (не использовалась 3 дня).
- `archived` — в архиве (30+ дней без активности).
- `deleted` — сгорел по истечении 30 дней без использования.

**Повторное резервирование:** сгоревший (`deleted`) УИП можно зарезервировать заново тем же
номером — сервис повторно резервирует его в ЧЗ, обновляет дату резервирования и возвращает в
`reserved_local`.

## Что автоматизировано (периодические процессы)

- Обновление токена СУЗ (каждые 6 часов).
- Удаление неиспользованных УИП (30 дней), закрытие (3 дня), архивация (30 дней).
- Очистка старых логов и записей задач.
- Синхронизация заданий и кодов с «Молвест.Маркировка» (раз в час).
- Синхронизация справочников и Национального каталога (раз в сутки).
- Мониторинг резерва (пороги 50/80/90%) и контроль сгорания (<7 дней) с уведомлениями по почте.
- Регистрация зарезервированных УИП через отчёт о нанесении.
- Архивация устаревших кодов маркировки.

> Актуальные интервалы — список `SCHEDULE` в
> `app_scheduler/management/commands/run_scheduler.py`.
