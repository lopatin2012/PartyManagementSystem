# 08. Обучение сотрудников

Материал для онбординга и инструктажа. Сценарии — по ролям.

## 1. Вход и роли

- Вход: `/auth/login/`. Выход — кнопка «Выйти» в правом верхнем углу.
- Роли (назначает администратор через `/admin/`):
  - **«Админ»** — полный доступ;
  - **«Просмотр»** — только страница УИП (+ генерация, если выдано право на запись).
- Если видите «Доступ запрещён» — у вашей учётной записи нет нужной роли; обратитесь к
  администратору.

## 2. Страница «УИП» (`/uip/`)

Что видно:
- таблица УИП с фильтрами по номеру, статусу, артикулу, датам производства/резервирования;
- пагинация (100 записей на страницу);
- статус-бейджи; значок ⚠ — признак рассинхрона с ЧЗ.

Действия:
- **«Сгенерировать УИП»** (кнопка `btn-generate`) — доступна администраторам и пользователям с
  правом на запись в `uip`;
- **«Синхронизировать с ЧЗ»** — только администратор;
- **«Зарезервировать»** для черновика — только администратор.

## 3. Как сгенерировать УИП (пошагово)

1. На странице `/uip/` нажмите **«Сгенерировать УИП»**.
2. Выберите продукт (поиск по артикулу/названию/GTIN).
3. Укажите **дату производства**.
4. Выберите **способ генерации**: «Локальный номер партии», «Честный Знак» или «Вручную».
5. При необходимости укажите **номер производственной партии** (0–999); для типа «Обычный»
   поле скрыто.
6. Проверьте **предпросмотр номера** (показан разбор по частям и тип формирования).
7. Нажмите **«Сгенерировать»**. Появится результат; список обновится.

> Формат локального номера зависит от типа формирования продукта
> (`type_formation_uip`): обычный, партия в начале, партия в конце, НатураПРО.

**Ручной ввод («Вручную»).** Появляется поле «Номер партии (серийная часть)» — 1–12 символов
(цифры, латиница и `/ . , -`). Полный номер собирается как `GTIN(14) + дата ГГММДД(6) +
серийная часть` и должен быть **ровно 32 символа**. Под полем показывается проверка: найден ли
номер в СУП (локально) и, при уходе из поля, в резерве ЧЗ. Номер резервируется в ЧЗ как
локальный.

## 4. Как зарезервировать черновик (админ)

В таблице у УИП со статусом **«Черновик»** нажмите **«Зарезервировать»** → подтвердите.
УИП уйдёт в «Честный Знак» и станет `reserved_local`.

## 5. Поиск (`/search/`)

- Введите номер УИП или код маркировки — тип определится автоматически.
- Управляющие символы DataMatrix (GS/FNC1) можно не чистить — сервис отбросит их сам.
- Результат — **карточки**: код/номер, продукт, GTIN, артикул, завод, цех, линия,
  **внешний номер задания**, партия, статусы, даты. Для УИП — блок «Производственные задания».

## 6. Синхронизация заданий (`/cz/sync/`, админ)

- Список заданий из внешнего сервиса: статус, статус синхронизации, дата последней синхронизации,
  сообщение/ошибка.
- Кнопки ручной синхронизации; **«Полная синхронизация»** (`POST /cz/sync/all/`) — выгрузка
  изменённых заданий по всем заводам + коды.

## 7. Национальный каталог (`/cz/nk/`, админ)

- Поиск/фильтры товаров НК, готовность к производству.
- Запуск синхронизации НК (кнопка) — параллельный запуск из другого процесса вернёт конфликт (409).
- Прогресс виден на странице и в окне «Фоновые задачи».

## 8. Фоновые задачи (админ)

- Виджет в шапке → «Подробности»: расписание, последний/следующий запуск, ошибки.
- Если задача завершилась ошибкой, помеченные задачи повторяются через 5 минут.

## Частые вопросы (FAQ)

**Почему кнопки «Сгенерировать»/«Синхронизировать» не видны?**
Недостаточно прав. Генерация — право на запись в `uip`; синхронизация — роль «Админ».

**УИП «сгорел» (deleted). Можно вернуть?**
Да, при повторном запросе на тот же номер сервис заново резервирует его в ЧЗ и возвращает в
`reserved_local`.

**Почему статус в ЧЗ и в системе расходятся?**
Смотрите значок ⚠ (рассинхрон). Запустите синхронизацию (админ).

**Как понять, к какому продукту относится код?**
Поиск по коду покажет карточку с продуктом, GTIN, артикулом и местом производства.

**Код не находится в поиске.**
Проверьте, что код синхронизирован с внешнего сервиса (страница «Синхронизация»). Код ищется по
точному совпадению или началу строки.

**Задача синхронизации падает.**
Проверьте доступность сервера завода (`Factory.ip_address`/`port_address`) и раздел «Фоновые
задачи». Метка завода не сдвигается при сбое — окно будет повторено.
